# Design

Llamancer — Summon your models. OMP-first. Not OMP-only.

Hex is the proposed llama necromancer mascot. Dracula is the default palette. Five views: Library, Discover, Downloads, Server, Settings. Contextual shortcuts, keyboard and mouse, responsive panes and confirmation dialogs. Delegate detailed resource monitoring to btop. English UI initially.

Keep the interface lightweight and distinguish engine settings from per-request generation parameters.
